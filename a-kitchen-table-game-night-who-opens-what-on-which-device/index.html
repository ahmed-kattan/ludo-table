A kitchen-table game night: who opens what on which device

Ahmed Moaz · 18 November 2026

A game night at one table with several devices needs a plan, or it turns into a technical support session. These are the roles I would set before the first game.

The host's device

One person, the host, opens the table on a phone or laptop. They choose the game, set the rules and start. They need a stable connection and a screen they can read.

Everyone else

Everyone opens the link on a phone, tablet or computer of their own. They type a name. Nothing to install and no account. If a device is old, a browser tab is still enough.

A shared screen, optional

If you have a big screen, put the host's device on it. Some games, like Snakes and Ladders and Property Rush, are fun to watch together. Others, like Who's the Spy, need private screens.

One-phone modes

When there are not enough devices, Who's the Spy has One phone, which takes up to twelve people, and Ludo and Snakes and Ladders have a One phone mode in which you pass the phone and whoever's turn it is rolls.

Roles

  1. Host. Opens the table, sets the rules and starts.
  2. Helper. Helps any guest who cannot join.
  3. Timekeeper. Watches the clock and calls the end.

Connections

The table signal reads green, yellow or red. If a device drops, the player is told and can retry. Their seat is held.

Which games for which table

The seat limits decide it: four for Ludo, six for Property Rush, eight for Trivia Tavern and Snakes and Ladders, three to eight for Who's the Spy online, and twelve for Draw and Guess.

How long to plan

Across the table log (13 September to 30 October 2026) the medians for finished games range from 4.3 minutes for Snakes and Ladders up to 30.5 for Property Rush.

Where to start

The same page everywhere

Whatever device a guest has, a drawing is made on the same 800 by 600 page, so a phone and a laptop show the same picture. That is why you can mix devices at one table.

The roles in a line

Host, helper and timekeeper.

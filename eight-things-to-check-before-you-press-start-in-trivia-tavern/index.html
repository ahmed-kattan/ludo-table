Eight things to check before you press start in Trivia Tavern

Ahmed Moaz · 14 November 2026

A good quiz is mostly settled before it starts. These are the eight things I check as a host, in order.

1. Who is here

Trivia Tavern seats two to eight. If more people want to play, open a second table.

2. Is everyone connected

The signal on a table is green, yellow or red. If someone is yellow or red, wait or ask them to retry.

3. The categories

Pick the subjects yourself, or leave it on Mixed and each category gets an even share. There are nine.

4. The mode

Because the race is the default, the first right answer scores the most. If you want a gentler night, choose the mode where every right answer scores its points less up to a quarter for time.

5. The length

A new table has 20 seconds per question, 10 questions per round and 3 rounds. In the table log (13 September to 30 October 2026) the median finished game ran ten minutes.

6. The extras

The last round counts double by default. A tie goes to sudden death by default. The final bet is off by default. Decide whether to switch it on.

7. The difficulty

Shuffle is the default, so questions climb from easy to hard. Fix it on easy for children.

8. The rules, aloud

Each question has four answers, one right, with no help and no skip. A closest-number question closes each round. Read them out.

The checklist

  1. Seats.
  2. Signals.
  3. Categories.
  4. Mode.
  5. Length.
  6. Extras.
  7. Difficulty.
  8. Rules.

Where to try it

Run the checks on Boardit's Trivia Tavern before your next game. Guests need only a name.

Why a host should be boring

Good hosts are predictable. They read the rules the same way every time, and they do not change settings midgame. A table that knows what will happen relaxes, and relaxed players play better and argue less. Leave the surprises for the questions.

The spare questions

If sudden death is on, the game draws five spare questions at the start so that a tie can be settled without a pause. The extras you switch on in the lobby are checked once, before play.

Before you start

A minute of checks saves ten of confusion.

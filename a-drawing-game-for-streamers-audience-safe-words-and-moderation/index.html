A drawing game for streamers: audience-safe words and moderation

Ahmed Moaz · 12 October 2026

A drawing game online can work well on a stream, but only if you decide who sees which words before you go live. In Draw and Guess, which seats 2 to 12 players, the host controls four things: a private table, a hand-written word list, the guest list, and whether the room code ever appears on screen. The game does not filter what players type. So the safe setup is the one where you choose every word and every seat yourself.

Start with the word list

Draw and Guess ships with its own word bank, covering things such as objects, animals, food, places, brands, apps and parts of the body. The words were picked to be quick to sketch. It was not written with a particular platform's rules in mind, and I have not screened it against any.

The host can type their own list instead. Rules for that list, from the code:

  • Words are separated by commas.
  • Each word is 1 to 32 characters.
  • Duplicates are dropped, so "Cat, cat" counts once.
  • With at least ten different words, the table can use the list on its own, with none of the built-in words mixed in.
  • The rest of the table never sees the list as a list. Words reach it only as turns come up.

For a stream, I would use the list on its own. Then every word that can come up is one you wrote. Ten different words is the minimum, and thirty is a safer number for a long session, since repeats come around quickly otherwise.

A test for each word

Before a word goes on the list, ask four questions.

  1. Can it be drawn without anatomy, a real person or a logo that someone might dispute?
  2. Is it tied to a news event or a joke that only some of your viewers will get?
  3. Do its partial letters read badly? As the timer counts down the game uncovers as many as three letters, so fragments of the word are visible to the table. Say them out loud with the gaps.
  4. Would you be comfortable if a viewer clipped the drawing without the word?

One more point about the screen you share. The host decides whether the drawer sees two, three, four or five words, and the drawer picks one. If you capture your whole screen, viewers see what you see, including the words you are offered. Keep the game in a window that is not captured, or let a guest draw.

Who sits at the table

A table seats 2 to 12 players, and the host picks 4, 6, 8, 10 or 12 seats. Viewers in your stream chat cannot guess unless they hold a seat, so the real question is how you hand out seats.

The room code works like a key: anyone who has it can sit down. Tables show up on public lists unless the host switches the table to private, and a private table admits only those who hold the code. Three habits follow from that:

  • Make the table private before you share anything.
  • Send the code to the chosen players in a direct message. Do not show it on screen or paste it into chat.
  • If a code leaks, close the table and open a new one.

A simple way to pick players is to draw names from your chat and send each winner the code privately. It is fair and it keeps you out of the argument.

What the game does not screen

This is the limit you need to know about. The code screens players' typed names, but only before the public open-table lists show them: an insult, a slur, a link or a long number is swapped for a neutral name there. On a private table nothing is listed, so that screen does nothing for you.

I searched the code for a filter on guesses, on chat lines and on custom words, and found none. A guess is capped at 100 characters and a player can send 60 lines per drawing, but what those lines say is up to the player. The terms of use ask people not to use chat, names, word lists or drawings to harass or to post sexual or hateful content. A terms page is a rule, not a filter.

I also did not read any streaming platform's own rules, so I cannot say what yours allows. Read them.

How to remove a player

The tools are simple and they differ by moment.

In the lobby, the host can remove a player directly. A removed player cannot see the room again or sit back down.

During a game, the table votes. The number of votes needed is the number of players minus two, with a floor of two. At four players that is two votes. At twelve it is ten. So a vote is fast at a small table and slow at a full one, which is one more reason to keep a stream table small and to choose its players beforehand.

A checklist for the night

  • Write the word list yourself, thirty words or more, and say each one out loud.
  • Set the table to private.
  • Choose seats ahead of time and send the code privately.
  • Keep the drawer's screen out of the capture.
  • Agree one rule with the table in advance: anyone who breaks it is voted out and does not get the code again.

Try it before you go live

Run one test game with friends, two or three is enough, and a list of ten harmless words. Watch how the letters appear on the clock. If you want to run a private table before you go live, Boardit is free and runs in a browser. Then you will know what your audience sees, and what they never do.
